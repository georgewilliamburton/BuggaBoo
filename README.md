# 🎨 BuggaBoo Studio

A child-friendly web-based animation maker designed to be simple, colorful, and fun. Create frame-by-frame animations right in your browser—no installation needed!

## ✨ Features

- **🖌️ Drawing Tools** - Draw, select, fill, and erase with easy-to-use tools
- **🎨 Color Palette** - 13 preset colors plus custom color picker
- **📏 Multiple Brush Sizes** - 5 brush sizes from 2px to 32px
- **🎬 Frame-by-Frame Animation** - Create and manage animation frames with preview thumbnails
- **📦 Asset Library** - Save and reuse your favorite drawings across frames
- **🧅 Onion Skinning** - See the previous frame as a guide while drawing
- **📚 Layers Panel** - Drag-and-drop layer ordering and visibility controls
- **↩️ Undo/Redo** - Full history with 50-state memory
- **💾 Save & Load Projects** - Save your work and continue later
- **📤 Export Animation** - Download frames as PNG images
- **⌨️ Keyboard Shortcuts** - Quick access to tools and actions

## 🚀 Getting Started

**Simply open `index.html` in any modern web browser!** No server, no installation, no setup required.

## 🎯 Canvas Sizes

Choose from 7 canvas sizes when creating a new project:
- **Square** (512×512) - Perfect for balanced drawings
- **Cinema** (768×432) - Widescreen format
- **Portrait** (432×768) - Vertical format
- **Wide** (768×384) - Ultra-wide
- **Large** (640×640) - Bigger square
- **YouTube** (1280×720) - HD video format
- **Fullscreen** - Maximum available drawing space

## ⌨️ Keyboard Shortcuts

- **D** - Draw tool
- **S** - Select tool  
- **F** - Fill tool
- **L** - Toggle layers panel
- **Space** - Add new frame
- **Shift+Space** - Duplicate frame
- **Ctrl+Z** - Undo
- **Ctrl+Y** - Redo
- **Ctrl+A** - Select all
- **Ctrl+S** - Save frame

## 🛠️ Built With

- **Fabric.js** - Canvas manipulation
- **HTML5 Canvas** - Drawing and rendering
- **Pure JavaScript** - No frameworks, just vanilla JS
- **localStorage** - Asset persistence

## Usage

**To Start:** Double-click `index.html` or open it in any web browser.

**No server or installation needed!** All features work completely offline in your browser.

## Development

To modify specific features:
- **Styling**: Edit CSS files in `css/`
- **Tools**: Edit `js/tools.js`
- **Canvas behavior**: Edit `js/canvas.js`
- **Frame system**: Edit `js/frames.js`
- **Keyboard shortcuts**: Edit `js/shortcuts.js`

## Browser Compatibility

Requires a modern browser that supports:
- HTML5 Canvas
- ES6 JavaScript
- Fabric.js 5.3.0
- CSS Grid & Flexbox
